3.8 Interfaces

Interfaces

En programación, una interfaz define qué métodos y propiedades debe tener una clase, pero no cómo se implementan.
Es decir, una interfaz es un contrato que las clases deben cumplir.

Ejemplo teórico:

En JavaScript puro no existen interfaces

JavaScript no tiene una palabra clave como interface, así que no podemos obligar formalmente a una clase a cumplir una estructura.

Pero sí podemos simular interfaces usando distintos enfoques:

Forma 1: Convención (el enfoque más común)

Simplemente se documenta que una clase debe implementar ciertos métodos.

Usar TypeScript (la forma moderna y tipada)

En TypeScript, que es un superconjunto de JavaScript, sí existen interfaces reales.
Esto es muy común en proyectos modernos porque permite detección de errores en tiempo de desarrollo.

Si Gato no implementa alguno de los métodos, TypeScript lanza un error de compilación.
👉 Esto mejora mucho la seguridad y mantenibilidad del código.
