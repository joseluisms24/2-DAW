2.4.3 Ejercicios resueltos

1. Coerción implícita

Ejercicio: ¿Cuál es el resultado de la siguiente operación? Explica por qué sucede.

let resultado = "10" * 2; console.log(resultado);

Respuesta esperada:

  • El resultado será 20. Aunque "10" es una cadena de texto, al realizar la multiplicación, JavaScript convierte implícitamente "10" en el número 10 para poder realizar la operación.

2. Conversión entre números y strings

Ejercicio: ¿Qué imprimen las siguientes líneas de código y por qué?

let a = 5 + "2"; let b = 5 - "2"; console.log(a); console.log(b);

Respuesta esperada:

  • a será "52" debido a la concatenación de la cadena "2" con el número 5.

  • b será 3 porque JavaScript convierte "2" a un número para realizar la resta.

3. Comparaciones sueltas (==) versus comparaciones estrictas (===)

Ejercicio: Evalúa las siguientes comparaciones. ¿Qué resultado esperas en cada caso?

console.log(0 == "0");   // Comparación suelta console.log(0 === "0");  // Comparación estricta

Respuesta esperada:

  • El primer console.log dará true porque 0 y "0" son convertidos al mismo tipo (número) antes de ser comparados.

  • El segundo console.log dará false porque los tipos son diferentes (número vs cadena) y la comparación estricta no realiza conversión de tipos.

4. Conversión de tipos en valores booleanos

Ejercicio: ¿Qué imprimen las siguientes líneas de código y por qué?

js
Copiar código
console.log(Boolean("false"));   // Cadena no vacía console.log(Boolean(0));         // Número cero console.log(Boolean(""));        // Cadena vacía console.log(Boolean([]));        // Array vacío

Respuesta esperada:

  • "false" se convierte a true porque cualquier cadena no vacía es considerada truthy.

  • 0 se convierte a false porque es un valor falsy.

  • "" se convierte a false porque es una cadena vacía, lo que también es falsy.

  • [] (un array vacío) se convierte a true porque un objeto (incluso vacío) es considerado truthy.

5. Conversión de objetos a tipos primitivos

Ejercicio: ¿Qué imprimen las siguientes operaciones y por qué?

js
Copiar código
let arr = [1, 2]; let obj = { key: "value" }; console.log(arr + 3); console.log(obj + 3);

Respuesta esperada:

  • arr + 3 resultará en "1,23" porque el array [1, 2] se convierte en la cadena "1,2", y luego se concatena con "3".

  • obj + 3 resultará en "[object Object]3" porque el objeto obj se convierte en la cadena "[object Object]", que luego se concatena con "3".

6. NaN

Ejercicio: ¿Qué sucede en la siguiente operación? ¿Cuál es el valor de resultado?

js
Copiar código
let resultado = "hello" / 2; console.log(resultado);

Respuesta esperada:

  • El resultado será NaN porque la cadena "hello" no puede convertirse en un número válido, y dividir un número por una cadena no numérica resulta en NaN.

7. Peculiaridades del operador + con cadenas y números

Ejercicio: ¿Cuál es el valor de resultado1 y resultado2? Explica por qué.

js
Copiar código
let resultado1 = "5" + 1; let resultado2 = 5 + 1 + "3"; console.log(resultado1); console.log(resultado2);

Respuesta esperada:

  • resultado1 será "51" porque el operador + realiza una concatenación de la cadena "5" con el número 1.

  • resultado2 será "63" porque primero se suma 5 + 1, lo que da 6, y luego este valor se concatena con "3", resultando en la cadena "63".

8. Conversión de null y undefined

Ejercicio: ¿Qué imprimen las siguientes líneas y por qué?

js
Copiar código
console.log(null + 5); console.log(undefined + 5);

Respuesta esperada:

  • null + 5 imprimirá 5, porque null se convierte a 0 antes de realizar la suma.

  • undefined + 5 imprimirá NaN, ya que undefined no puede convertirse en un número válido, y cualquier operación aritmética con undefined da como resultado NaN.

9. Conversión explícita

Ejercicio: Completa el código siguiente para convertir el valor de str en un número de manera explícita y realizar una suma correcta.

js
Copiar código
let str = "42"; let num = 8; let resultado = /* tu código aquí */; console.log(resultado); // Debería imprimir 50

Solución:

js
Copiar código
let str = "42"; let num = 8; let resultado = Number(str) + num; // Conversión explícita a número console.log(resultado); // 50

Explicación: Se usa la función Number() para convertir la cadena "42" a un número antes de sumar 8.
